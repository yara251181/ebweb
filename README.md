# 🎯 AKTU Study Notes Platform

A **premium, production-ready study notes platform** for AKTU University with advanced content protection, UPI payments, and professional engineering brand experience.

## ✨ Features

### 🛡️ Security & Protection
- **PDF Content Protection** - Multi-layer security preventing downloads/copying
- **JWT Authentication** - Secure user authentication system  
- **Payment Security** - Razorpay UPI integration with signature verification

### 💳 Payment System
- **UPI, Cards, Net Banking** - Multiple payment methods
- **Razorpay Integration** - Production-ready payment gateway
- **Free & Premium Notes** - Flexible pricing model (₹0 - ₹99)

### 🎨 User Experience
- **Dark/Light Mode** - Smooth theme switching
- **Premium Engineering Design** - Professional brand identity
- **Responsive Design** - Mobile-first approach
- **YouTube Integration** - Video resource links

## 🏗️ Tech Stack

### Frontend
- **React.js 18** - Modern React with Hooks
- **Vite** - Fast build tool & dev server
- **Tailwind CSS** - Utility-first styling
- **Axios** - HTTP client
- **React Router** - Navigation

### Backend
- **Python Flask** - REST API framework
- **SQLite3** - Database
- **JWT** - Authentication
- **PyMuPDF** - PDF processing & protection
- **Razorpay** - Payment integration
